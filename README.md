## 🎯 Learning Approach

<div align="center">

| 📖 Step 1 | ✍️ Step 2 | 🧠 Step 3 | 💻 Step 4 |
|:---:|:---:|:---:|:---:|
| Write the theory in my own words | Practice the syntax | Build logic with small problems | Write, run and test the program |
